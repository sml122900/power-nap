## 막힌 것 / 알게 된 것

- **`expo prebuild`의 segfault는 종료 코드만으로는 원인을 못 찾는다.** 에러 메시지
  없이 exit 139로 죽어서 `EXPO_DEBUG=1`로 마지막 단계(tar 전개 완료 직후)를 봐야
  `%TEMP%` 문제라는 걸 알 수 있었다.
- **gradle 스택트레이스는 prefab 실패의 진짜 원인을 안 보여준다.** `ProcessException:
  ... prefab_command.bat ... exit value 1`까지만 나오고, 실제 원인(cmd가 한글 경로를
  못 읽음)은 `.../logs/<abi>/prefab_stderr.txt`를 직접 열어야 나왔다.
- **keystore는 이미 백업돼 있었다.** "오프사이트 사본 없음"이라고 먼저 보고했는데
  C: 안에서만 찾아본 결과였고, 실제로는 `E:\프로젝트 백업`에 7/23부터 2벌이 있었다.
  없다고 단정하기 전에 다른 드라이브까지 봤어야 했다.
- **비밀번호가 keystore 바로 옆에 평문으로 있었다.** `power-nap.txt` 첫 줄이
  비밀번호였고 keystore와 같은 폴더 — 그 폴더 하나가 새면 키와 비밀번호가 같이 샌다.
- **백업 문서의 경로가 죽어 있었다.** `power-nap-backup.txt`의
  `RELEASE_KEYSTORE_PATH=C:\Users\sm553\keys\...`는 이번 사고로 사라진 경로다.
  백업만 믿고 복구하려 하면 없는 경로를 따라가게 된다.
- **영구 시스템 `JAVA_HOME`은 Adoptium JDK 21이다.** 릴리즈 빌드 2회를 실제로
  통과시킨 건 Microsoft JDK 17이라, 체크리스트 블록을 안 돌리고 새 터미널에서
  그냥 빌드하면 검증된 것과 다른 JDK로 돌아간다.
